📖 リーダーモード (推奨):
余計な広告や複雑なスクリプトを除去し、本文記事とメイン画像のみを抽出。iPad Air（1GB RAM）でも絶対にクラッシュしません。

🎨 クリーンHTMLモード:
元のWebサイトの見た目や配置を維持します。フリーズや落ちる原因になる重いJavaScriptのみを削除して表示します。

📝 テキストのみモード:
画像すら読み込まず文字のみ表示。通信量を削減したい場合や超高速で読みたい時に最適です。

🖥 自宅PCで起動する最速変換プロキシ（任意）

パブリックプロキシを使用せず、ご自宅のMacやWindows PCで以下のNode.jsコードを実行すると、より高速かつ安全にiPadへとWebページを変換転送できます。

// 1. server.js として保存し、`npm install express axios jsdom @mozilla/readability cors` を実行 const express = require('express'); const axios = require('axios'); const { JSDOM } = require('jsdom'); const { Readability } = require('@mozilla/readability'); const app = express(); app.use(require('cors')()); app.get('/proxy', async (req, res) => { try { const targetUrl = req.query.url; const response = await axios.get(targetUrl, { headers: { 'User-Agent': 'Mozilla/5.0 (Windows NT 10.0; Win64; x64)' } }); const dom = new JSDOM(response.data, { url: targetUrl }); const reader = new Readability(dom.window.document); const article = reader.parse(); res.json({ title: article ? article.title : 'No Title', content: article ? article.content : response.data }); } catch (e) { res.status(500).send(e.toString()); } }); app.listen(8080, () => console.log('Proxy running on port 8080'));
